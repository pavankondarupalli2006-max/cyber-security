# Password Strength Analyzer

A simple, responsive web app that checks password strength and gives suggestions for creating a stronger password.

## Features

- Checks password length and character variety.
- Looks for repeated characters, common passwords, and simple sequences.
- Shows password-strength feedback and a checklist.
- Includes a show/hide option for the password field.
- Can generate a random password suggestion.
- Analyzes the password in the browser; it is not saved or sent to a server.

## Built With

- HTML
- CSS
- JavaScript

## Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code **Live Server** extension.

## Privacy

This project is a learning demo. Do not enter a password that you currently use for an important account.
